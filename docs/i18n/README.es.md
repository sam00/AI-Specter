# 👻 Specter AI

### Pentesting automatizado con IA, desde tu terminal

> ⚠️ **Solo uso autorizado.** Specter aplica una lista de alcance permitida y
> exige indicadores explícitos para cualquier acción activa o de explotación.

Specter conecta **Claude, GPT, Ollama o cualquier LLM** a un flujo de pentest
real y **enruta cada fase al modelo más adecuado**. Ejecuta herramientas con
control de alcance, prioriza los hallazgos con IA y genera tres informes.

## Inicio rápido

```bash
pipx install ai-specter
specter quickstart        # interfaz en español: SPECTER_LANG=es specter
```

La documentación completa está en inglés: [`README.md`](../../README.md).
