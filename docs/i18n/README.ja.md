# 👻 Specter AI

### ターミナルから実行する、AI駆動の自動ペネトレーションテスト

> ⚠️ **許可された利用のみ。** Specter はスコープの許可リストを強制し、
> アクティブ／エクスプロイト操作には明示的なフラグを必要とします。

Specter は **Claude、GPT、Ollama などの任意の LLM** を実際のペンテスト
ワークフローに接続し、**各フェーズを最適なモデルにルーティング**します。
スコープガード付きでツールを実行し、AI で結果をトリアージし、3 種類の
レポートを生成します。

## クイックスタート

```bash
pipx install ai-specter
specter quickstart        # 日本語UI: SPECTER_LANG=ja specter
```
